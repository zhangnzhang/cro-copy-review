# cro-copy-review

[English](README.md) | 简体中文

一个用转化文案专家的眼光审网站和营销文案的 AI Skill：按 10 个维度打分（满分 100），找出最拖转化的 3 个问题，每个问题都给可以直接粘贴的改写。

可以作为 Claude 的 Skill 使用，也可以给任何能读 Markdown 指令文件的 AI 工具用。

## 能得到什么

给它一段标题、产品描述、CTA 按钮、FAQ、弹窗或邮件，它会返回：

- **打分表**：10 个维度，分别是标题钩子、利益大于功能（权重最高）、情绪共鸣、具体性、客户原话、节奏与可读性、信任与社交证明、CTA 清晰度、结构框架、类比与比喻。每个维度都附一句诊断。
- **最拖转化的 3 个问题**：每条都有原文引用、为什么拖转化、可直接粘贴的改写。
- **整段改写（可选）**和**最多 3 条下一步建议**，包括写好 A/B 两个版本的测试方案。
- **快速扫描模式**：只想知道「主要问题是啥」时，用 30 条是非题快速过一遍。

完整示例见[示例审稿](examples/sample-review.md)。

## 和「帮我把文案改好」有什么不同

- **每个判断都有标尺。** 每个维度都写明了 10 分、6 分、2 分分别长什么样，打分前后一致，也方便讨论。
- **讲依据，不凭感觉。** 内置一个证据库，收录 Nielsen Norman Group、Baymard、CXL、Copyblogger、Moz/Conductor、PowerReviews、西北大学 Spiegel 研究中心、VWO 和 Unbounce 的测试等研究数据。它能讲清楚「为什么这样改」，而不是给泛泛的建议。每个数字都标了出处和可信度等级。
- **不编造证据。** 改写里需要评分、客户数量或评价时，它会写 `[真实评价数]` 这类占位符，绝不自己编。
- **尊重品牌语气。** 刻意的风格手法（短句、一词句、自问自答）不会被当成「节奏差」扣分。

## 安装

**Claude：** 把 `skills/cro-copy-review/` 复制到 `~/.claude/skills/`（或项目里的 `.claude/skills/`），然后说：

> 从转化角度审一下这段首屏文案：「……」

**其他 AI 工具：** 把 `skills/cro-copy-review/SKILL.md` 作为指令文件给它，参考文件会按需读取。

## 文件结构

```
skills/cro-copy-review/
├── SKILL.md                    # 审稿流程、输出模板、审稿铁律
└── references/
    ├── dimensions.md           # 10 个维度的打分标尺
    ├── evidence.md             # 研究数据与公开测试，附出处和可信度等级
    ├── examples.md             # 框架、功能转利益与 CTA 改写库、反例
    └── checklist.md            # 30 条快速扫描清单
examples/
└── sample-review.md            # 完整审稿示例
```

## 关于出处

[`evidence.md`](skills/cro-copy-review/references/evidence.md) 里每个数字都标了出处和等级：**A**（已对照原始出处核实）、**B**（附公开出处链接）、**C**（有人引用过但找不到原文，Skill 引用时必须说明「据报道」）。Skill 引用时要说明这项研究测的是什么，不能把别人的结果当成对你网站的预测。框架和示例也都标明了是框架或示例。发现哪条说法需要更好的出处，欢迎提 issue。
